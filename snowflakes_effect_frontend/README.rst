**Table of Contents**

.. contents::
   :local:

Installation
============

Go to the Apps menu and install the module *Snowflakes Effect Frontend* (`snowflakes_effect_frontend`).

Configuration
=============

No configuration is required.

Usage
=====

Once installed, the module will automatically enable a snowflake animation and background music in the frontend interface. A small toggle button will appear in the **bottom right corner** of the screen to enable or disable the music.

Known Issues / Limitations
==========================

* Audio may not play automatically due to browser autoplay restrictions.
* The toggle button to stop the music may require **two clicks** the first time to work correctly, due to browser autoplay handling.
* The toggle button appears in the bottom-right corner instead of using a themed icon like in the backend.
