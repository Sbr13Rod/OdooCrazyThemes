Module to add a festive snowflake effect and background music to the Odoo backend.

**Table of Contents**

.. contents::
   :local:

Installation
============

Go to the Apps menu and install the module *Snowflakes Effect Backend* (`snowflakes_effect_backend`).

Configuration
=============

No configuration is required.

Usage
=====

Once installed, the module will automatically enable a snowflake animation and background music in the backend interface. A small Santa Claus icon will appear at the bottom of the screen to toggle the effects on and off.

Known Issues / Limitations
==========================

* Audio may not play automatically due to browser autoplay restrictions.
* The Santa Claus toggle button does not appear with a shaded background, which may affect visibility depending on the theme.
