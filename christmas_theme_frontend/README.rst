Installation
============

Go to the Apps menu and install the module *Christmas Theme Frontend* (`christmas_theme_frontend`).

Configuration
=============

No configuration is required.

Usage
=====

Once installed, this module will automatically apply a snowy background, holiday-inspired UI styling to the Odoo frontend.
