Installation
============

Go to the Apps menu and install the module *Christmas Theme Backend* (`christmas_theme_backend`).

Configuration
=============

No configuration is required.

Usage
=====

Once installed, this module will automatically apply a snowy background, holiday-inspired UI styling, and optional Christmas music to the Odoo backend.
A Santa Claus icon will appear in the top-left of the backend interface to toggle the snow and music effects.

Known Issues / Limitations
==========================

* Background music may not auto-play due to browser autoplay policies.
* Some input fields, checkboxes, or radio buttons may not render correctly with the custom theme in all views (especially in forms or wizards).
* The Santa Claus toggle button may blend with certain themes and be hard to spot.
